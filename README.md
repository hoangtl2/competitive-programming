Repository lưu trữ hành trình luyện tập Cấu trúc dữ liệu & Giải thuật.

## 📂 Cấu trúc
- **`LeetCode/`**: Daily Challenges, Contests, Topics.
- **`Codeforces/`**: Daily, Contests, Phân loại theo Rating (0800 - 1200+).
- **`AtCoder/`**: ABC, ARC, Educational DP Contest.
- **`Templates/`**: Code mẫu thuật toán chuẩn dùng lại.
- **`Notes/`**: Ghi chú lý thuyết và mẹo tối ưu.
